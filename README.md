# Telecom Egypt Intelligent Assistant

A production-ready RAG (Retrieval-Augmented Generation) chatbot for Telecom Egypt that answers customer queries using the official website as the primary knowledge base, with support for multi-lingual processing and document upload.

## 📋 Overview

This project implements an intelligent assistant for Telecom Egypt that:
- Answers customer questions using Telecom Egypt's official website
- Handles queries in Arabic, English, and Egyptian dialect
- Allows users to upload and query additional documents (PDF, DOCX, TXT, HTML)
- Provides source citations for all answers
- Delivers a professional chat interface

## ✨ Features

- **Multi-lingual Support**: Arabic, English, and Egyptian dialect
- **Document Upload**: PDF, DOCX, TXT, HTML formats
- **Source Citations**: Every answer includes references to sources
- **Professional UI**: Streamlit-based chat interface
- **Local Processing**: All data processed locally for privacy
- **On-Premises Ready**: Docker deployment support
